# research

AI 생성물(영상·사진·음성·음악·글) 판별 앱의 시장조사 자료입니다. 조사 시점은 2026-11-14입니다.

## 파일

- `01-market-research.md`: 최종 보고서
- `raw/`: 영역별 원자료
  - `<영역>.research.json`: 1차 웹 조사 결과
  - `<영역>.verify.json`: 1차 조사에 대한 적대적 검증(반박 시도) 결과
  - `<영역>.digest.md`: 검증 결과를 반영한 영역별 요약본

## 조사 영역

| 키 | 내용 |
|---|---|
| image | AI 생성·조작 이미지 탐지 |
| video | AI 생성 영상·딥페이크 탐지 |
| audio | AI 음성(보이스피싱)·AI 음악 탐지 |
| text | AI 생성 글 탐지 |
| provenance | 빅테크 출처증명·워터마크(C2PA, SynthID)와 규제 |
| korea | 한국 시장(국내 업체, 공공 수요, 피해 통계) |
| reliability | 탐지 기술의 실제 신뢰도와 포렌식(수사) 수준 요건 |
| patents | 특허·데이터셋 라이선스 장벽 |
| market | 시장 규모·투자·비즈니스 모델 |

## 주의

- 웹 검색 한도 때문에 일부 항목은 검색으로 확인하지 못했습니다. 그런 항목은 요약본에 "미확인(사전 지식)"으로 표시되어 있습니다.
- 벤더가 주장한 정확도와 독립 평가 결과는 구분해서 적었습니다.
- 특허 관련 내용은 법률 자문이 아닙니다. 실제 출시 전에는 변리사의 FTO(실시 가능성) 검토가 필요합니다.
